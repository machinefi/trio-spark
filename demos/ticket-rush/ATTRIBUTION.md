# Data attribution

- **Source:** [Bitext customer-support LLM chatbot training dataset](https://huggingface.co/datasets/bitext/Bitext-customer-support-llm-chatbot-training-dataset)
- **Creator:** Bitext Innovations
- **License:** [Community Data License Agreement – Sharing, Version 1.0](https://cdla.dev/sharing-1-0/)
- **Adaptations:** a random sample of 1,000 requests, with template placeholders such as `{{Order Number}}` filled with sample values, and the dataset's 11 categories mapped onto 8 queues

`tickets.json` is a derivative of the dataset and is shared under CDLA-Sharing-1.0. The demo code in this directory is Apache-2.0.
