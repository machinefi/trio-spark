# Falling Blocks

Trio-Spark chose one legal rotation and column from current board state on each
turn. The selected move was applied to the next board without a heuristic
fallback or edited placement.

**Recorded production run:** 30 seconds · 16 model calls · 7 lines cleared ·
764 points · 0 API errors
