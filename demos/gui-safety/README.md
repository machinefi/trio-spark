# GUI Agent Safety

A deterministic policy gate removed forbidden actions, then Trio-Spark chose
among the remaining actions from structured accessibility state. The run opened
invoice details, compared records, and handed the anomaly to a human.

**Recorded production run:** 24 seconds · 3 model calls · bounded human handoff ·
0 API errors

The input is structured text; this demo makes no pixel vision claim.
